# Telegram-бот с краткосрочной и долгосрочной памятью (RAG)

Учебный проект: бот-продавец учебных курсов по английскому языку с памятью на основе **aiogram 3.x**, **LangChain** и **ChromaDB**.

## Возможности бота

- **Краткосрочная память** - хранит историю диалога в `dict[user_id]` (последние **10** сообщений)
- **Долгосрочная память (RAG)** - загруженные документы конвертируются в эмбеддинги и сохраняются в **ChromaDB** с персистентным хранением в папке `./memory`
- **Работа с документами** - поддержка форматов **PDF**, **TXT**, **DOCX**
- **Автоматическая разбивка** - документы разбиваются на чанки размером **~500 символов** с перекрытием
- **Точный ответ** - бот отвечает **только на основе загруженного документа**, не выдумывает информацию
- **LangChain Chains** - логика построена с использованием **LangChain LCEL**

## Технологический стек

- Python 3.10+
- aiogram 3.31.0
- LangChain 0.3.x
- OpenAI API (gpt-5-mini) через proxyapi
- ChromaDB (persistent)
- pypdf, python-docx

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd "VPf06. Память для AI"
```

### 2. Создание и активация виртуального окружения

**Windows (cmd):**
```cmd
python -m venv venv
venv\Scripts\activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка .env

Файл `.env` уже присутствует в проекте. Проверьте, что в нём указаны актуальные токены:

```env
BOT_TOKEN=ваш_токен_телеграм_бота
OPENAI_API_KEY=ваш_ключ_proxyapi
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
DEFAULT_MODEL=openai/gpt-5-mini
```

> **Важно:** Токены берутся именно из `.env` файла. `BOT_TOKEN` и `OPENAI_API_KEY` обязательны.

### 5. Запуск бота

```bash
python bot.py
```

При успешном запуске в консоли появятся логи о старте бота.

## Как пользоваться ботом

1. **Старт** - отправьте `/start` боту
2. **Загрузка документа** - отправьте файл в формате `PDF`, `TXT` или `DOCX` с информацией о курсах
   - Бот сохранит файл, извлечет текст, разобьет на чанки (~500 символов)
   - Сохранит эмбеддинги в ChromaDB в папке `./memory`
3. **Задать вопрос** - просто напишите вопрос по загруженному документу
   - Бот проверит короткую историю диалога
   - Найдет релевантные фрагменты в векторной базе
   - Сформирует ответ **только на основе документа** через LangChain цепочку
   - Сохранит диалог в краткосрочную память (до 10 сообщений)
4. **Доп. команды:**
   - `/clear` - очистить историю диалога
   - `/status` - проверить статус (количество сообщений в истории, чанков в БД)

## Тестирование

В проекте уже есть готовый тестовый документ для проверки работы бота:

- `english_courses_sample_for_rag.txt`
- `english_courses_sample_for_rag.pdf`
- `english_courses_sample_for_rag.docx`

**Рекомендуемый порядок тестирования:**

1. Запустите бота
2. Отправьте боту файл `english_courses_sample_for_rag.pdf` (или любой из вариантов)
3. Дождитесь сообщения об успешной индексации
4. Задайте вопросы, например:
   - "Сколько стоит курс Бизнес-английский?"
   - "Какие акции есть?"
   - "Можно ли оплатить в рассрочку?"
   - "Есть ли информация о курсах программирования?" (должен ответить, что в документе нет такой информации)

## Особенности реализации

- **Функции по ТЗ вынесены отдельно:** `load_document()`, `embed_chunks()`, `retrieve_context()`, `answer_question()`
- **Краткосрочная память:** хранится в `dict[user_id]` в памяти бота, обрезается до последних **10** сообщений
- **Долгосрочная память:** ChromaDB с `persist_directory="./memory"`, коллекция `english_courses_docs`
- **Разбивка:** `CharacterTextSplitter` с `chunk_size=500`, `chunk_overlap=50`
- **RAG-логика:** при каждом вопросе происходит поиск релевантных чанков через `similarity_search`
- **LangChain LCEL:** цепочка `prompt | llm | StrOutputParser()`
- **Жёсткий промпт:** модель ограничена ответом только по контексту из документа
- **Асинхронные хендлеры:** все обработчики aiogram асинхронные
